Lecture 3 Python Lab Resources

Files are synthetic and created for educational use.

Key files:
- em_wavelengths.csv: representative electromagnetic wavelengths.
- chromatic_test.png / chromatic_pixel_values.csv: chromatic-light exercises.
- grayscale_test.png / grayscale_values_16x16.csv: grayscale intensity exercises.
- radiance_luminance.csv: radiance, luminance, and subjective brightness data.
- radar_velocity_20x20.csv / radar_velocity_heatmap.png: signed Doppler velocity map; for this lab negative = approaching, positive = receding.
- single_sensor_stream.csv / single_sensor_target.png: serial samples for single-sensing-element reconstruction.
- sensor_strip_lines_12x20.csv / sensor_strip_target.png: line-sensor reconstruction data.
- sensor_array_20x20.csv / sensor_array_20x20.png: complete 20x20 sensor array values.
- sensor_volume_slice_*.csv / sensor_volume_8x20x20.npy: slices for 3-D volume construction.
- sampling_quantization_source.png: sampling and quantization source image.
- dpi_test_pattern.png: spatial-resolution / DPI exercise.
- ccd_cmos_lowlight_scene.png / ccd_cmos_parameters.csv: CCD/CMOS exercises.
